# stapel-catalog — module notes

- Generated by the `stapel.catalog` convention from the build: published feature modules only (no
  demo, e2e, showcase, sample), versions from `VERSION_NAME`, toolchain pins from
  `gradle/libs.versions.toml` (`APP_VERSIONS`, `APP_LIBRARIES`, `APP_PLUGINS` in build-logic).
- `checkPublishedCatalog` fails on any pre-release version or consumer module in the TOML.
- A generated app's build depends on this catalog, the BOM and the two plugins only, never on this
  repository's `build-logic`.
