# stapel-auth-ui — seams and invariants

- **Material-free (R9):** only `stapel-ui` wrappers and slots; Material reaches tests only
  (`skikoTest` renders every screen with `FoundationSkin` and `Material3Skin`).
- **Stateless screens:** `SignInScreen`, `OtpCodeScreen`, `TotpChallengeScreen`,
  `ForcedPasswordChangeScreen`, `LockedScreen`, `GuestUpgradeScreen`, `SessionsScreen`,
  `SignOutConfirmDialog`, `AccountMenu` take a state class and emit events; only typed text lives in
  the composable. The binding to the domain presenters maps presenter state → these states.
- **Override table:** `AuthScreens` / `DefaultAuthScreens` / `LocalAuthScreens`. The sign-in screen
  draws its steps through `LocalAuthScreens`, so replacing a step replaces it inside the default screen.
- **Auth widgets:** `AuthSkin` through `StapelSkin.extension(AuthSkinKey)` (session row, method
  button); everything else is a `StapelSkin` slot.
- **Methods:** only `SignInMethod` members render (e-mail, phone, password). A method the client cannot
  complete (OAuth, magic link, SSO, passkey, QR) has no member and is never drawn.
- **Strings:** `AuthUiBundle` (en, ru), key names = the web pair's keys; mobile-only keys are listed in
  `AuthUiMobileOnlyKeys` and checked against the web fixture (`WebParityTest`). Error text goes through
  `stapel-result`'s ladder: register `authErrorCatalogs()` (contract English + `AuthErrorTextsRu`,
  generated by `scripts/gen_error_texts.py` from the backend's `translations/errors.ru.json`).
- **Navigation:** `authNavContribution` declares `auth.login` (`/login`), `auth.security` (`security`
  under `profiles.settings`) and the embed `auth.account_menu` (`topbar.end`) with the web manifest's
  ids, paths, placement, order and surfaces (fixture `src/jvmTest/resources/web`).
- **Layout:** `StapelPage` applies the gutter; screens never add root horizontal padding. Wider than a
  phone, the sign-in column is a bordered card (`PaneMeasure.Narrow`). Screens with their own top bar
  are avoided: the chrome names the destination (a single-line bar title truncates at 200 % text).
- **Tested:** each screen's states and events with both skins, the override table, skin delegation,
  named actionable nodes, one editable node for the code field, touch targets ≥ 44 dp on a phone, no
  clipped text at 200 % in en and ru.
- **Do not:** add Material or Coil; write literal user-facing text; navigate from a screen (emit an
  event); show the mock OTP code (the hint says only that nothing was sent).
