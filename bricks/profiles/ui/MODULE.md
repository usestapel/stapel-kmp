# stapel-profiles-ui — seams and invariants

- **Material-free (R9):** only `stapel-ui` wrappers and slots; Material reaches tests only (`skikoTest`
  renders every screen with `FoundationSkin` and `Material3Skin`).
- **Stateless screens:** `ProfileSettingsScreen`, `LanguageScreen`, `NotificationsScreen`,
  `ContactsScreen`, `ConnectionsScreen`, `PublicProfileScreen` take the domain presenter's state
  (`stapel.profiles.presentation`) and emit its intents; navigation leaves through callbacks
  (`onOpen`, `onOpenPerson`) and the page slot through `pageActions`. Confirmations (block, delete a
  number) and "show the number" are the only local UI state.
- **Bindings:** `ProfileSettings`, `ProfileLanguage`, `ProfileNotifications`, `ProfileContacts`,
  `ProfileConnections`, `PublicProfile` remember the presenters through `ProfilesPresenterFactory`
  (chained to the app's factory) and draw through `LocalProfilesScreens`.
- **The settings container:** its sections are `ResolvedDestination.children` of `profiles.settings`
  in the navigation's order — whatever libraries installed under it (`auth.security` names this id as
  its parent). Nothing here knows the auth brick.
- **Avatar:** `AvatarPicker` (the app's platform picker) is the one wiring point; without it, or without
  an uploader in the domain, "Change avatar" is not drawn. The picked `FilePart` goes to
  `ProfileSettingsIntent.SetAvatar` (upload + one PATCH in the domain). Avatars render through
  `StapelAvatar(image = StapelImage)`, i.e. the app's `LocalStapelImages` loader.
- **Strings:** `ProfilesUiBundle` (en, ru): the web pair's keys (`ProfilesStrings`, generated by
  `scripts/gen_strings.py` from `@stapel/profiles-react`'s `keys.ts`/`ru.ts`) plus mobile-only keys
  under `profiles.ui.*` (`ProfilesUiStrings`). Error text: `profilesErrorCatalogs()` = the contract's
  English + `ProfilesErrorTextsRu` (generated by `scripts/gen_error_texts.py` from the backend's
  `translations/errors.ru.json` at the pinned commit).
- **Navigation:** `profilesNavContribution` declares the six web destinations with the web manifest's
  ids, paths, placement, order, visibility and surfaces (`WebParityTest`, fixture
  `src/jvmTest/resources/web`); `profiles.public` renders page slot `page.actions`.
- **Descriptor:** `stapel.profiles.ui.di.ProfilesBrick(avatarUpload, picker, screens)`: `profilesModule`,
  the navigation, strings, error catalogs and presenter factory; no session of its own (install it with
  a sign-in owner). `nav-manifest.json` is exported from it (`checkNavManifest`, `checkNavParity`).
- **Tested:** each screen's events with both skins in en and ru; no unresolved key on any screen at
  200 % text in either locale; the avatar change only with a picker and an uploader; block only after
  the confirmation; no actions for oneself or an anonymous viewer; another library's destination under
  settings becomes a section.
- **Do not:** add Material or Coil; write literal user-facing text; navigate from a screen.
